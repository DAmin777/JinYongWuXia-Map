# 古卷轴深色主题 UI 优化设计

## 概述

将金庸武侠地图从浅色宣纸风格改为古卷轴深色主题，保留浅色地图瓦片作为视觉焦点，新增搜索和小说筛选功能，增强动效体验。

## 配色体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 面板背景 | `#1a1410` | 深褐墨色，卷轴底 |
| 面板卡片 | `#2a2118` | 稍浅褐，用于卡片/悬浮区 |
| 宣纸纹理叠加 | `rgba(244,234,222,0.03)` | 极淡宣纸纹理，增加质感 |
| 金色强调 | `#c9a84c` | 标题、边框、选中态 |
| 朱红强调 | `#c23531` | 交互态、门派标签 |
| 正文文字 | `#d4c5a9` | 暖米色，柔和不刺眼 |
| 次要文字 | `#8a7d6b` | 暗米色，描述文字 |
| 分割线 | `rgba(201,168,76,0.2)` | 淡金分割 |

字体保持不变：Ma Shan Zheng（标题）+ ZCOOL XiaoWei（正文）。

纹理：面板区域叠加极淡宣纸噪点纹理（复用 `rice-paper.svg`，降低透明度），地图区域保持现有宣纸风格。

## 布局与组件

### 左侧控制面板

保留现有结构，视觉改造：

- 背景：`#1a1410` + 宣纸纹理
- 标题区：金色文字 + 底部金色分割线
- 筛选按钮：深底金色描边，选中态填充金色
- 人物列表：卡片深底 + 悬浮时金色边框微光
- 选中人物：朱红左边框 + 背景微亮 + "追踪中"金标

新增区域（标题下方、筛选按钮上方）：

- **搜索框**：圆角深色输入框，金色 placeholder，左侧放大镜图标
- **小说筛选器**：水平滚动标签条，每本小说一个标签，选中态金色

### 右侧详情侧边栏

- 背景：`#1a1410` + 宣纸纹理
- 门派标签：朱红底金边
- 名胜标签：金色底深色字
- 关联人物/武功：chip 样式标签，深底金边
- 关闭按钮：金色叉号

### 地图区域

- 保持现有浅色宣纸瓦片不变
- 地图与面板交界处：添加金色竖线分隔，增强层次感

### 轨迹线重新设计

- 金色虚线（`#c9a84c`, dashArray）替代朱红实线
- 添加 CSS 流光动画（dashOffset 渐变），营造"内力运行"效果
- 途径点标记：金色圆点 + 序号

## 动效设计

| 场景 | 动效 | 实现 |
|------|------|------|
| 面板悬浮 | 金色边框渐现（0.2s） | `transition: border-color` |
| 人物卡片选中 | 左边框朱红渐入 + 背景微亮 | `transition: all 0.3s` |
| 侧边栏开关 | 水平滑入/滑出（0.3s ease） | 现有 `translate-x` 保留 |
| 搜索聚焦 | 输入框金色边框 + 微微放大 | `transition + scale(1.02)` |
| 标签选中 | 金色填充渐变（0.2s） | `transition: background-color` |
| 地图标记悬浮 | 标记放大 + 发光 | `transform: scale(1.3)` + `box-shadow` |
| 轨迹线 | 流光动画（dashOffset 周期渐变） | CSS `@keyframes` |
| 页面加载 | 面板从透明渐入 | `opacity 0→1, 0.5s` |

## 新增功能

### 搜索功能

- 位于左侧面板标题下方
- 输入时实时过滤人物列表和地图标记
- 支持按人物名、地点名、武功名搜索
- 空结果时显示"未找到相关武林秘闻"

### 小说筛选器

- 位于搜索框下方，筛选按钮上方
- 水平滚动标签条，每本小说一个标签
- 多选：可同时选多本小说
- 选中后：地图只显示相关地点 + 人物列表只显示相关人物
- 与类型筛选器（门派/名胜）联动

## 实现策略

采用方案 A（渐进改造）：在现有组件上逐步改造样式，不重构组件结构。

改动范围：
1. Tailwind 主题配置（新增深色系颜色变量）
2. `index.css`（新增深色面板样式、轨迹流光动画关键帧）
3. `ControlPanel.jsx`（深色样式 + 搜索框 + 小说筛选器）
4. `Sidebar.jsx`（深色样式）
5. `MapView.jsx`（轨迹线金色虚线 + 流光动画、标记悬浮动效）
6. `App.jsx`（搜索和筛选状态管理）
